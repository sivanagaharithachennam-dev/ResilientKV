Important methodology note:
The initial RocksDB benchmark uses RocksDB's default
WriteOptions, while ResilientKV currently performs synchronous
WAL file synchronization for every write.

Therefore these initial measurements should not be treated as
a direct apples-to-apples performance comparison.

A controlled durability comparison should be performed before
drawing performance conclusions.
